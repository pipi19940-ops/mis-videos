# Mis Videos

Sitio de videos personal, alojado gratis en GitHub Pages.

- **Agregar un video:** pestaña *Actions* → *Agregar video* → *Run workflow*.
- **Subir un video propio:** pon el `.mp4` en la carpeta `videos/` (máx. 100 MB) y agrégalo con la URL `videos/nombre.mp4`.
- La lista de videos vive en `videos.json`; también puedes editarla a mano.
